How to use this page
  1. Nothing to install and no account. Open this page and tap Add person.
  2. It starts in Demo mode with three invented people. Tap My people to switch to your own, empty list. The two lists are stored separately.
  3. For each person add dated affiliations (a company now, one before), notes and promises. Dates are loose text: 2024 or 2024-06. Leave the end empty for "current".
  4. Use Export JSON for a backup file. Import JSON adds copies of the people in a file; it never overwrites anyone.
  5. On a phone, use your browser's Add to Home screen to open it like an app.
What stays Android-only
  • Linking a phone contact through the system contact picker. A web page cannot read your contacts, so people here are not linked to Samsung or Google contacts.
  • The Kunjung handoff (jumpa://encounter/...). It opens the Android app only.
  • No sync. This page and the Android app keep separate data. Nothing moves between them automatically.

Same on both: people with dated affiliations, notes, promises, archive instead of delete, and a separate demo set.

Get the Android app
  1. Download jumpa-v0.1.1.apk (release notes).
  2. Open the file. If Android asks, allow installs from your browser or files app for this one install.
  3. Optional: check the SHA-256 matches 8d2f7e055f4168c7202564dbdd27d39f19e696711a7351f433ab7d0cfa906aec.

Test release, signed, zero Android permissions. Physical-phone behavior is not fully verified.

Privacy

Everything is saved in this browser's local storage. Nothing is uploaded: this page has no server, accounts or analytics. Clearing site data erases your people, and exports are plain unencrypted text. Anyone using this browser profile can read them.
